# 🧧 微信红包大作战 - 高度自定义版

一个支持2-20人实时对战的微信红包游戏WebSocket服务器，部署于Render平台。

## ✨ 特性

- **2人即可开局**：无需等待，2人就是完整对局
- **高度自定义**：所有游戏参数房主可调
- **四大游戏模式**：手速、记忆、反应、团队战
- **防作弊系统**：点击频率检测、坐标校验、时间戳验证
- **团队战模式**：5种角色技能 + 团队技能系统

## 🎮 游戏模式

### 1. 手速模式 ⚡
红包同时出现，比拼点击速度

### 2. 记忆模式 🧠
先显示金额3秒，记忆后抢夺

### 3. 反应模式 👀
红包随机闪现，3秒消失

### 4. 团队战模式 ⚔️
- 2v2起，支持2v2/3v3/.../10v10
- 5种角色：突击手、干扰者、侦察兵、守护者、幸运星
- 团队技能：红包雨、金额翻倍、敌方干扰

## ⚙️ 自定义参数

### 基础设置
| 参数 | 范围 | 默认值 |
|------|------|--------|
| 总人数 | 2-20人 | 4人 |
| 游戏时长 | 10-120秒 | 30秒 |
| 红包总数 | 2-50个 | 15个 |
| 总金额 | 1-2000元 | 100元 |

### 金额类型
- **random**：二倍均值法随机分配（传统）
- **fixed**：房主预设每个红包具体金额
- **range**：设置最小-最大金额区间随机
- **equal**：所有红包金额相同

### 游戏机制开关
- 显示他人光标位置
- 允许负分（踩炸弹）
- 连击加成
- 幸运保护（保底金额）
- 团队战：允许同队抢红包

### 高级参数
- 炸弹红包概率：0-50%
- 红包出现速度：0.5x-3x
- 技能冷却系数：0.5x-2x

## 🚀 部署到 Render

### 1. Fork/上传代码
将代码上传到GitHub或GitLab

### 2. 创建Render服务
1. 登录 [Render](https://render.com)
2. 点击 "New +" → "Web Service"
3. 连接你的代码仓库
4. 配置如下：
   - **Name**: hongbao-game-server
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Plan**: Free

### 3. 环境变量（可选）
```
NODE_ENV=production
PORT=10000
```

### 4. 部署
点击 "Create Web Service"，等待部署完成

## 🔌 API 事件

### 客户端发送
- `createRoom` - 创建房间
- `joinRoom` - 加入房间
- `updateSettings` - 更新设置
- `startGame` - 开始游戏
- `grabPacket` - 抢红包
- `selectRole` - 选择角色（团队战）
- `useSkill` - 使用技能
- `useTeamSkill` - 使用团队技能
- `updateCursor` - 更新光标位置

### 服务端广播
- `roomCreated` - 房间创建
- `playerJoined` - 玩家加入
- `playerLeft` - 玩家离开
- `settingsUpdated` - 设置更新
- `gameStarted` - 游戏开始
- `packetSpawned` - 红包出现
- `packetGrabbed` - 红包被抢
- `gameEnded` - 游戏结束
- `skillUsed` - 技能使用

## 🛡️ 防作弊系统

1. **点击频率检测**：单秒超过5次视为作弊
2. **坐标校验**：点击位置必须在红包范围内（容差10px）
3. **时间戳校验**：红包出现前点击无效
4. **金额校验**：固定金额模式服务器存储，客户端只传索引
5. **技能CD**：服务器端严格计时
6. **负分保护**：如关闭负分，炸弹最多扣到0

## 📝 使用说明

### 创建房间
1. 输入昵称
2. 选择游戏模式
3. 调整游戏设置（可选）
4. 点击"创建房间"
5. 分享房间号给好友

### 加入房间
1. 输入昵称
2. 输入6位房间号
3. 点击"加入房间"

### 2人快速开局
- 创建房间后立即获得房间号
- 分享给对方
- 2人即满，房主可立即开始
- 无需等待其他人

## 🔧 Render免费版注意事项

2. **自动重连**：前端已实现自动重连机制
3. **首次访问**：休眠后首次访问可能需要等待10-30秒唤醒
